# Apartmán AK Slatiňany

Webové stránky apartmánu ke krátkodobému ubytování ve Slatiňanech (dvojjazyčné CZ / EN).

Statický web (HTML + CSS + JS), připravený pro nasazení na GitHub Pages.

## Struktura

- `index.html`, `galerie.html`, `vybaveni.html`, `cenik.html`, `okoli.html`, `kontakt.html` — české stránky
- `en/` — anglická verze týchž stránek
- `css/style.css` — společný design (šalvějová zelená + krém)
- `js/main.js` — mobilní menu, filtr galerie, lightbox
- `fotky/` — fotografie apartmánu
- `images/okoli/` — fotografie výletních cílů (Wikimedia Commons)
